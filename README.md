# HANNAH

ブラウザで動く、個人用のメモアプリです。Apple のメモに近い3ペイン（フォルダ／一覧／本文）の画面で、書いたものはすべてお使いのブラウザの中（localStorage・IndexedDB）に保存されます。サーバーへは送りません。

https://urtyottaro.github.io/HANNAH/

## 主な機能

- 1行目がタイトルになる、常に編集状態のメモ（自動保存）
- フォルダ分け、ピン留め、ゴミ箱、インライン検索
- メモ一覧のスワイプ操作（左：書き出し・ゴミ箱／右：ピン留め、強く右へで自動ピン留め）
- 音声入力、録音（メモに添付）
- 外観テーマ（アクセント・背景・文字の3色から作る配色、ライト／ダーク／自動）
- フォントの切り替え（端末のフォントや、読み込んだフォントファイル）
- メモの書き出し（.txt）、全データの JSON 書き出し・取り込み
- PWA としてインストール可能

## 開発

```bash
npm install
npm run dev      # 開発サーバー（http://localhost:5173）
npm run build    # dist/ に出力
```

Vite + バニラ JavaScript です（フレームワークなし）。`src/js/` に機能ごとのモジュール、`src/css/` にスタイルがあります。構成の概要は `CODE.md` と `handoff.md` を見てください。

## Windows 版（デスクトップアプリ）

Electron で包んだインストーラー（`HANNAH-Setup-x.x.x.exe`）を、GitHub の Releases から取れます。ブラウザ版と同じ画面です。

- ブラウザ版とデスクトップ版は、保存場所が別です。メモは自動では共有されないので、設定の「データ」から JSON を書き出して取り込んでください。
- デスクトップ版では、音声入力は使えません（Chrome の音声認識に頼っているため）。録音は使えます。
- 署名をしていないため、初回は Windows の「PC を保護しました」が出ます。「詳細情報」→「実行」で進めます。

作り方：

```bash
npm run electron:start   # 手元で起動して試す
npm run dist:win         # インストーラーを release/ に作る
```

`v0.4.0` のようなタグを付けて push すると、GitHub Actions が Windows 用を作って Releases に添付します。

## フォントについて

このリポジトリにはフォントファイルを含めていません。画面のフォントは、Google Fonts と、お使いの端末にあるフォントを使います。商用フォントを使う場合は、各フォントのライセンスに従ってください。
